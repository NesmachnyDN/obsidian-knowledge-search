# Development and packaging tools

`build.mjs` emits `dist/main.js`, `dist/standalone-worker.js` and `dist/manifest.json`, externalizing Obsidian and Node built-ins and rejecting bundled third-party npm packages. `test.mjs` runs synthetic TypeScript tests with a 60-second suite timeout. `licenses.mjs` inventories locked packages and upstream notices (development inventory, not a security audit).

`npm run package:standalone` creates a minimal, deterministic, unsigned local Standalone package under ignored `build/standalone-package/`, with SHA-256/byte ledger in the adjacent `build/standalone-package.sha256.json`. `npm run test:package` adds negative tampering/path/link tests; `node scripts/standalone-package.mjs verify` independently validates the generated package. The packer refuses to overwrite unknown or changed output; for a changed source build remove only the explicitly generated package and ledger. No model downloads, global dependencies, production Vault access or public release actions occur.

`OKS_STANDALONE_PACKAGE_DIR="$PWD/build/standalone-package" bash scripts/obsidian-host-smoke.sh` validates that exact package in a disposable real Obsidian host/profile/Vault; without the variable the same script continues the legacy `dist/` smoke. `unshare -Urn` may optionally be used on supported Linux to prove the host test while only loopback networking exists. It does not create a signed binary release or a user-facing installer.
