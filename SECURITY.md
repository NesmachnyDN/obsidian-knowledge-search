# Security and privacy

OKS is intended to process vault contents locally. Design goals only until validated. No telemetry, cloud inference or external document transmission by default. Explicit provisioning of reviewed model artifacts is distinct from runtime egress. Treat document contents as untrusted data, never as executable instructions. Reject traversal and symlink escape, enforce allowed roots and bounded input sizes, and avoid executing embedded document code or arbitrary commands. Authenticate any loopback interface; prefer local stdio and keep network listeners off by default. Logs and exported diagnostics are metadata-only by default and redact private paths. Do not publish private fixtures, indexes, embeddings, crash dumps, credentials or workstation details.

Report vulnerabilities privately to the repository maintainer via GitHub private vulnerability reporting if enabled. Do not include sensitive details in public issues. No guaranteed response SLA.

## Optional local or cloud AI API egress (ADR-0015)

The offline text-occurrence/Properties baseline never requires a provider, secret, outbound request, model download or listener. An AI API may be local or remote only by explicit user configuration. **Configured credentials are not consent to transmit content.** Cloud mode is disabled by default; before sending any query, document chunk, candidate passage, expansion context or embedding input, enforce per-Vault/per-source scope and classification policy, deny unknown or forbidden content, minimize transmitted text, and present the external-processing boundary clearly. Check endpoint allowlists, TLS validation, API token scope, provider jurisdiction/routing/retention contract and user authorization. Avoid unapproved third-party routing and sending private data to public CI or benchmark services.

Use dedicated AI-service credentials stored outside tracked repository/Vault artifacts, never reuse Cloud.ru S3 credentials. Do not include API keys, raw text, full URLs containing tokens, confidential provider request/response payloads or embedding values in logs, diagnostics or GitHub. Bound timeouts, batch size, concurrent requests, quotas/costs and retries; cancel on disable/unload. On denial, offline network loss, API timeout, 429 or model mismatch, preserve autonomous basic search, expose typed unavailable/error for the requested AI mode, and leave the last verified local indexes consistent. A local API is not implicitly trusted or offline-capable: verify endpoints, ownership, isolation and no-route operation before claiming it.
