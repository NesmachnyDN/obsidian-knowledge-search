# OKS Advanced document ingestion wire — protocol version 3

Status: **OKS-05C candidate**, not an accepted retrieval/search or model-inference protocol. Semantic authority: [portable-model](portable-model.md); production codec: `engine/advanced_protocol.py` and `plugin/src/advanced/protocol.ts`. Health-only stdio v2 in ADR-0009 and Standalone in-process API v1 remain unchanged.

## Framing and trust

One **canonical UTF-8 JSON object plus one LF** per request/response; sorted Unicode-codepoint keys recursively (not UTF-16 code-unit order), compact punctuation, literal UTF-8 rather than ASCII escaping, finite numbers, no BOM, no duplicate keys, no extra data. Both runtimes use **ECMAScript JSON.stringify-compatible shortest-round-trip binary64 numeric spelling**: negative zero becomes `0`; absolute values from `1e-6` inclusive to `1e21` exclusive use plain decimal; other finite magnitudes use normalized exponents with no zero padding (positive exponents retain `+`). Python uses a dedicated recursive codec rather than `json.dumps` exponent formatting. A non-interoperable integer or unpaired surrogate is invalid; typed Properties with unrepresentable integer values are diagnosed as unsupported rather than coerced. TypeScript sorts keys by Unicode code points and both receivers enforce strict UTF-8 decoding and byte-for-byte canonical re-encoding. Golden-byte Python/TypeScript conformance includes decimal, exponent, negative zero, Unicode key ordering and native geometry. Canonical frames cannot contain unknown fields at any validated layer. Maximum request 8192 bytes; maximum response 8 MiB; one in-flight request per worker. Invalid framing terminates the worker. Stdio is process-private, **not** a multi-user authentication mechanism. No logging of frames, paths or source text.

Request (all fields mandatory): `{protocolVersion:3,requestId:48 lowercase hex,operation:"ingest",sourcePath:canonical vault-relative,rootPath:trusted absolute canonical vault root,scopeId:SHA-256 of canonical [rootPath,dev,ino] JSON,expectedSha256:lowercase raw-byte SHA-256,profileId:explicit supported extractor profile,deadlineUnixMs:safe integer,tokenizerSnapshot:explicit absolute pinned directory,tessdataPath:explicit absolute directory or null,artifactsPath:explicit absolute directory or null}`. The parent obtains source paths from Obsidian `TFile` and validates the raw bytes before request; the Python worker reopens via descriptor-relative `ScopedReader` and verifies root/version. No source bytes are included in request. A new 48-hex nonce is required per request; responses must echo it exactly. Deadline is checked before/after extraction and planning. Actual cgroup admission and offline/no-network controls are required before any source read.

Response (all fields mandatory): `protocolVersion,requestId,operation:"ingest",status,source, chunks, generationId, diagnostics, error`. `status` is one of `ok,partial,empty,failed,unsupported`. A failed/unsupported response has no chunks; an empty/failed source cannot advertise ready evidence; `source` is null when no verified content digest is available. A successful source version includes `sourceId,vaultRelativePath,sha256,sourceType,scopeId,profileId,extractionStatus,properties,wikiLinks,diagnostics,pageCount,blocks`. Result `generationId` is SHA-256 of a canonical generation descriptor containing `scopeId,sourceSha256,profileId,chunkIds,wireVersion`; it is not a search-generation claim.

Each block has `sourceId,sourceSha256,blockId,order,kind,originalText,headings,wikiLinks,clause,textNature,locator,cells`. A `textNature=table-cell-serialization` row is **not a verbatim excerpt**: individual `cells[].originalText` with native cell anchors are the source evidence. In every other block `originalText` is the original representation's text; when native original text cannot be verified the locator carries a diagnostic. `blockId` binds source digest, profile, block order, kind and exact originalText.

A locator has `locatorKind` (`markdown|native|unavailable`), `sourceVersion,blockOrder,charStart,charEnd,byteStart,byteEnd,lineStart,lineEnd,nativeItemRef,nativeRepresentation,contentLayer,locations,table,row,diagnostics`. Nullable fields stay explicit; `locations` are native page/geometry/coordinate-origin and **native-item-local** optional char span. A native cell bbox requires a valid `TOPLEFT` or `BOTTOMLEFT` coordinate origin and nonempty row/column ranges; bbox and origin must either both be absent or both be valid, with finite bounded coordinates and ordered left/right values; the native `BOTTOMLEFT` representation may legitimately have top greater than bottom. Invalid cell provenance is rejected before publication, not silently labelled verified. Markdown `charStart/End` are file-wide Unicode scalar offsets, with file-wide half-open UTF-8 offsets and one-based lines. Native block-wide `charStart/End` are null; native item spans only come from verified extractor anchors. No binary byte offset may be invented.

A chunk has `chunkId,sourceId,sourceSha256,profileId,sourceSlices,sourceLocators,originalText,contextualText,chunkPolicyId,serializationId,tokenizerFingerprint,effectiveTokenCount,diagnostics`. Source slices are ordered `{blockOrder,charStart,charEnd}` over original **block-local Unicode scalar offsets**. `contextualText` is model input, not user evidence. Token budget is exact under the pinned BGE-M3 tokenizer; no fallback estimator, no silent loss. Unlocated native slices cannot be served as verified EvidenceHits.

The future `EvidenceHit` record is **not emitted by ingestion**: it must bind `sourceId,sourceSha256,originalExcerpt,sourceLocators,rank,retrievalMode,indexGenerationId` (plus per-leg diagnostics) and is only valid with live source freshness and compatible, atomically published retrieval generation. Inventing a ranked hit from ingestion output is prohibited. The dense/hybrid modes stay unavailable until OKS-05D.

## Compatibility and failure

Worker verifies source content twice: before extraction via scoped descriptor reads and after extraction/planning. Parent verifies raw file SHA-256 again before accepting and before derived generation publication; any ambiguity returns `SOURCE_STALE` and suppresses evidence. Root change, profile mismatch, invalid source, unsupported format, missing tokenizer, absent/OOM cgroup, extraction partial, OCR failure and native unlocated text are separate diagnosed outcomes; fail closed when precise provenance cannot be verified. No extraction library or model is an optional **runtime fallback**. Index/cache is derived, never authoritative.
