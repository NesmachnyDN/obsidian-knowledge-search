# Frozen synthetic corpus v1
Independently invented fictional components and requirements; MIT repository terms. UTF-8 files are the reproducible source fixtures, with SHA-256 manifest. The oracle labels every physical nonblank line (including syntax) with its expected coarse type and literal text. Malformed front matter has no closing delimiter and must produce a diagnostic; its contents remain visible. The HTML-like payload is deliberately unsupported structure, not executable. Empty sources must be reported. The two Helios copies intentionally have identical bytes but distinct source identities.

Tuning/held-out judgments were authored before retrieval implementation. Grades: 2 directly answers, 1 supporting evidence, absent=0. Document grade is maximum span grade per path; unit is unique (path, 1-based physical line), with an exact original source slice. The lexical baseline uses line units, including table rows; syntax-only separators are preserved but not retrieved. Fixed K=5,10 denominators for precision; recall over positive units; nDCG uses 2^grade-1 gain and log2(rank+1); MRR uses first positive rank. Unanswerable queries excluded from positive averages, reported separately as false-positive counts/queries; no synthetic assertion that no results exist for ordinary lexical terms. Exact-ID query subset reports at least one grade-2 hit at K. No retrieval effectiveness threshold for this first baseline; zero invalid locators, unexplained lost spans and stale/forbidden hits are hard gates. A later paired comparison must predeclare margins and avoid tuning on held-out labels. This is a small authored pilot, not independent human annotation, representative production traffic or a statistical guarantee.

The retrieval function receives only query text and indexed sources, never judgments. Evaluate tuning before freezing the implementation and then evaluate held-out; do not change labels to improve scores. New corpus versions must preserve this version and its judgments.
