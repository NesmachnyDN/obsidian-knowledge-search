# Frozen 06B.4 evaluation protocol

ADR-0020 thresholds are unchanged. The checked-in v1 corpus and manifest are frozen before any held-out execution. Generated material is wholly synthetic and independent of application output. No tuning split or model selection is performed; any remediation is reported as a rerun of this exact held-out corpus, not a new independent sample. All 40 positive held-out queries are literal exact identifiers with bilingual text (10 per language/category); this intentionally tests authored-relation context retrieval rather than semantic paraphrase or broad real-world representativeness. Negative fixtures separately exercise ambiguity, unresolved links, cycles, navigation-only links and local private content. 512 stress notes extend the same 128-note set.

Use identical literal query, scope, limit 10 for lexical and graph. Rank distinct source IDs by first returned occurrence; evaluate grades 2/1/0 against frozen source labels, Recall@10, nDCG@10, MRR@10 and exact direct seed presence. Graph-required and ordinary categories are separate. Expected path precision/recall uses exact source/ordered author/endpoints/relation/direction; projected edge precision/recall includes exact original anchor text. All candidate/anchor locators are independently checked against raw UTF-8 bytes, codepoint offsets and physical lines, not only an engine status. Errors are not exclusions or successes. No unavailable AI role is counted; no provider requests/tokens/cost from graph. The graph operation is local only, including private fixtures, with no disclosure admission.

Resource protocol: separate clean process for 128/512; same actual bounded filesystem reader, worker parser and generation store as the existing standalone benchmark; no bypass of source checks or custom yield function. Record cold first retrieval separately and paired warm queries, alternating mode order by query index; added p95 is p95 of paired graph-minus-lexical durations. Measure five projection derivations using the already parsed exact generation (excludes authenticated source I/O), serialize actual projection; sample RSS and process high-water mark relative to ready Basic engine, CPU and source I/O counters, index disk bytes before/after graph, event-loop delay. Node event-loop measurement is not a substitute for real Obsidian UI. Test lifecycle/rollback separately and report actual real-host CLI/UI evidence. No acceptance on failure, no threshold relaxation.
