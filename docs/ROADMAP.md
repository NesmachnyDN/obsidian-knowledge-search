# Implementation roadmap

Dependency-order plan. Consult merged PRs for completion state; listed outcomes are not claims that a feature is already delivered. One bounded PR at a time, with independent exact-HEAD SDD review. Track execution in PRs/issues, not duplicate status ledgers.

**2026-11-23 product-owner rebaseline:** [ADR-0011](adr/0011-api-first-ai-optional-dense.md) supersedes the original mandatory offline local dense/hybrid Advanced MVP gate of ADR-0006 and earlier OKS-05 contracts. Preserve historical execution evidence; reconcile in-flight 05D work before an AI release or merge. Release Gate A is autonomous occurrence/Properties search; Gate B (AI API) and Gate C (advanced documents/OCR) apply only to products claiming those capabilities.

## Phase exits

- Foundation (00–01B): design and protocol tested; no unresolved blocker to the next slice.
- Document quality (02): measurable structure and token/provenance metrics, provisional policy; retrieval-quality confirmation in 03B.
- Retrieval (03): accepted ADR-0006, reproducible model-backed offline lexical/dense/hybrid experiment with compatible provenance/index and separate independent review; **not** a claim of standalone plugin feature. If model weights/permission or review are missing, phase exit is blocked.
- MVP (04–05): operational no-extra-dependency Standalone with offline occurrence/Properties/metadata, lifecycle and recovery; **Gate A is mandatory**. Provider-backed AI CAP-04/05 and advanced PDF/DOCX/OCR CAP-02/03 gates are mandatory only for separately claimed capabilities; cloud requires consent/security proof. Original two-gate local/offline AI requirement is superseded by ADR-0011.
- Advanced / adoption (06–08): individually benchmarked optional features and separate rollout authorization.

No branch, PR, task ID or numeric metric is evidence by itself. Before each next slice reconcile the roadmap with current implementation and review. Production vault indexing must wait for maintainer approval and stability checks.
