# OKS-06B.3a — explicit bounded graph expansion plan

Base 55dbb2f887a59c5d768b79c07fddb2e199bffb3b (#99, accepted 06B.2); ADR-0020, AC-11-GRAPH-03, ROADMAP 06B.3. Implement a pure internal, typed request parser and deterministic multi-source traversal plan from a host-authenticated scoped graph and verified lexical seeds. No public result, source reads, navigation, AI, provider, persistence or scope change; subsequent 06B.3b binds the plan to exact original evidence/lease/deadline and 06B.3c exposes local UI/API/CLI. Scope selectors reuse existing strict parser; explicit graph depth 0–2, direction outgoing/incoming/both, optional exact relation IDs, fan-out 1–16 distinct neighbors per expanded node, candidate count 1–32, lexical/Top-K 1–50. Use relation-only edges, never navigation or inferred facts. Preserve lexical seed order and rank; multi-source shortest path with deterministic tie by seed rank, path/edge ID; report unique candidates and Top-K omissions explicitly in the plan. Every edge and anchor must match scoped source versions, including author. Reject invalid configuration, cross-scope/foreign generation, malformed edge/seed lineage, unsupported editor-range, over-limit traversal and cancellation without partial success. No hardcoded personal metamodel, no new dependencies. Unit adversarial cases for direction, relation type, duplicates, cycles, tie, limits, scope/version and invalid requests. Full regression, exact independent review, CI.
