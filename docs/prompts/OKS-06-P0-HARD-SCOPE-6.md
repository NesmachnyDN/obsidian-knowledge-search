# OKS-06 P0.2b5a — host source-revision retirement prerequisite

Base: 7994fdd47f976ebb3364f0458cd59c24b556479b. Authority: AGENTS, SECURITY, SDD, SPEC CAP/AC-01/06/08/10, ARCHITECTURE, ROADMAP P0, ADR-0023, #149/#105, HARD-SCOPE-1–5 and merged #154. Standard bounded PHASE_RUN. This is a prerequisite, not activation or cumulative acceptance.

## Existing ownership and gap

The native adapter owns irreversible native scope retirement; the reader and standalone engine now observe it. The standalone engine separately requires an actual host-operation retirement signal for revocable policy and preview calls. The current native main wiring creates an unscoped reader and policy host calls do not yet bind a host-operation signal. SearchController already owns sourceRevision, sourceAuthorityCurrent, source retirement obligations/drains, shared reset and terminal seal. Reuse these; do not make a parallel revision matcher or policy issuer.

The first bounded host-side slice must bind an irreversible source-revision retirement seal to the existing SearchController source authority. It is only a constituent of a later full host-operation signal: it cannot by itself establish active-file identity, role/profile, credentials, lifecycle, current operation, provider configuration, or current callback. Do not pass an incomplete seal as PolicyHost.authority or enable native scope.

## Implementation boundary

Inspect existing source revision transitions, settings begin/end, nested source invalidation, trackSourceDrain, source retirement failure/overflow and terminal teardown. Expose a host-internal captured current revision and a passive irreversible retirement seal only while existing source authority permits capture and no shared transition is in progress. Seal the previous authority on revision/lifecycle loss before any observable result, new source work or relevant host callback; preserve exact concrete retirement obligations, nested waves, source-drain and fail-closed behavior. Do not let an existing reentrant retirement callback reopen a retired revision, replace an outstanding retirement target, skip a retirement obligation, or dispatch stale work. Respect the terminal seal ordering across sibling owners; do not introduce a new callback in the terminal logical seal before sibling authority is closed. Use a frozen read-only seal with a callback-free local retirement bit, rather than exposing an AbortSignal: abort dispatch would execute arbitrary synchronous listeners during terminal sealing and before sibling retirement. This constituent is not an operation AbortSignal and must not be passed as one. Subsequent operation integration must preserve the callback-free cut and existing engine contract, with a separately reviewed composition boundary. Ordinary lexical resets do not themselves advance source revision. If a new source drain starts inside an existing non-source retirement wave, advance the existing source revision before its pending state can become transiently false again. Terminal seal retires the captured bit without introducing a callback.

In scope: SearchController source-revision authority boundary, minimal cohesive internal helper if necessary, targeted synthetic tests and this contract. No main activation, native configuration subscription in production, role/preview signal plumbing, new source matcher, source writes, new dependency, storage schema, provider or producer calls, physical derived cleanup, expanded capability claim or unrelated refactor.

## Negative acceptance matrix

- Capture under current revision; successful source invalidation retires the old seal permanently; a newly eligible revision receives a distinct live seal only after the existing retirement barrier settles.
- Nested invalidation, synchronous existing retirement callback reentry, settings transition and failure, rejected/pending source drain, retirement failure/overflow, terminal unload and repeated retirement; no stale admission or missed concrete obligation, including empty-obligation invalidation.
- Retirement observed before any relevant observer/callback sees old publication rights; preserve shared reset behavior, source versus ordinary lexical revision distinction, and existing Basic/graph/evidence/chat/dense authority regression.
- Old seal remains retired after recovery; no revival and no new grants during retirement. Use generated synthetic data only. Instrument ordering and actual dispatch counts, not merely return codes.
- Full applicable validation: focused controller/retirement tests, full Node/Python, typecheck, build, license, isolated standalone package and contract checks, publication hygiene, diff check, exact-HEAD CI and separate independent full-diff review.
