## Scope

- Preserve the frozen Markdown corpus, original and reviewed 02A runs, and reader/retrieval behavior. Add an independently generated, versioned bilingual PDF/DOCX/scan fixture set and independently specified expected content, native hierarchy, table topology and page/coordinate evidence. Include multi-page files, numbered requirements, nested headings, headers/footers, repeated text, merged cells, an explicit negative and failed input; record generator and source hashes. No private documents.
- Evaluate pinned Docling native document structure, using the slim installation and format-specific extras where supported. Compare native PDF text layer and DOCX extraction with a relevant lightweight alternative (e.g. Poppler and OOXML/python-docx) on identical bytes. Use Tesseract CLI for local Russian and English OCR if verified language assets are available. Compare text completeness, structure and cell coverage, provenance, time, CPU and peak RSS. Do not mistake flat text, Markdown exports or heuristic headings for verified native structure.
- Extend canonical blocks narrowly and compatibly: distinguish literal Markdown byte/line spans from extracted format-specific item references, page, geometry and native text character spans; do not fabricate file-byte ranges for PDF or DOCX. Record table row/column and merged-cell ranges, available native provenance, reading order, hierarchy, and explicitly missing values. Preserve source bytes/hash, typed extraction statuses, safe diagnostics and extracted text distinct from derived context; do not change the lexical baseline to accept unchecked binary locators.
- Ensure bounded source reads and ZIP/PDF preflight, no archive traversal or external relationships, no execution of document content, fail visibly on malformed/empty/unsupported/partial inputs, and no silent text loss. Isolated subprocess with cgroup v2, no network at conversion time, no auto-downloads, no concurrent model tasks, per-input size/page/ZIP expansion/time and output bounds. Reuse Foundation safety primitives within their documented limitations; do not globally enlarge its 8 KiB Markdown freshness budget. No production Vault integration, embedding or chunking.
- Review exact resolved dependency versions, wheel licenses/notice files, transitives, installed and download size, optional model artifact identity/license/size, and runtime resource measurements. Pin only tested dependencies in an isolated environment. Use already available local artifacts or lightweight options first; no heavy model/runtime download without explicit approval. Keep model artifacts outside Git. Verify offline behavior rather than merely trusting a config flag. Record alternatives and actual limitations in an ADR/evidence. Claim only tested format/profile support; a missing mandatory PDF/scan/structure experiment remains a blocker, not a success or implicit fallback.

- V02B-04: license/size inventory, measured resource admission and process-tree bounds, no remote processing/automatic model download, documented alternatives and decision. All unsupported capabilities remain visible.

Actual OCR and extraction evidence required; an unprovisioned heavyweight artifact requires maintainer authorization and blocks this slice if no safe sufficient alternative is demonstrated.
