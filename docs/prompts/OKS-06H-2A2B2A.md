# OKS-06H.2-A2b2a — Retained host-owned conversation turn authority
Base: 6d1164e540eee625844cf6d38aa76f08615f8645 (PR #72 merged, develop checks green). Standard bounded PHASE_RUN. Authority: AGENTS, SECURITY, SDD, SPEC AC-11-CHAT-02/03 and AC-06/07/09/10/11, ADR-0018, OKS-06H, A1/A2a/A2b1, 05P and accepted 06A-R1/R2 lifecycle.
Close the retrieval-to-next-stage ownership gap without enabling chat disclosure. Extend the existing SearchController scoped retrieval machinery with a host-issued opaque session/turn owner and retained internal verified ChatScopeLease, exact engine/source/config binding, and a bounded continuation lifetime. Keep legacy A2b1 retrieval-only behavior/tests unchanged; the retained path must reuse the same admission/worker, not duplicate retrieval. Host owns lease and verified response, detached views only; no transferable capability to a lease, grant, credential or transport. One active turn across sessions and one shared generation admission across search/chat; search prepare/confirm must not steal a retained turn. Exact owner cancellation and retirement, cross-host/session/replayed owner rejected. Preserve physical outstanding work slot until settlement; logical revoke before callbacks; reuse ledger and active deadlines, fail closed on config, scope/source/generation drift, cancel, shared reset, unload, failed retirement, reentrancy. Retained turn is local-only and cannot call provider; explicit retirement/expiry frees slot only when safe. Validate identities/currentness on each await and on owner-checked detached reads; bound snapshot and pending lifetime, no retained history. No second controller/index/provider/grant issuer, no changes to legacy search classification, no native UI or credential storage. Subsequent A2b2b integrates generation/credential binding B-02; B-03 follows before any chat egress. Do not claim B-02, B-03, chat or operational readiness.
Focused deterministic tests: retain lease/admission after verified retrieval, foreign/replayed owner, concurrent search/chat admission, explicit cancellation and stale late callback, changed config/source/engine, reentrant retirement, timeout, failed retirement/unload, no network, detached data; preserve existing A2b1 and LIFE/SYS tests. Typecheck, full regression/build/package/licenses/audit, independent exact-head review, CI, merge and postmerge verification. No production Vault, real credentials, actual provider, new dependencies or hidden persistence.
