# OKS-06H-POLICY.2e2 — Linux durable lifecycle ledger substrate

Base: `c3e5b39e7e5ba10d91534bc9ff5563421331ef0b`. ADR-0019/0021, POLICY.2e/2e1, AC-11-POLICY-02/03, issues #78/#79/#105. Standard bounded implementation. Preserve the accepted production pilot and all Basic/Graph gates; no production lifecycle wiring, source writes, provider admission or network.

Select the Linux descriptor-anchored host-private backend, with separate current-anchor/lock and snapshot directories outside the Vault. Reuse reviewed private-directory and atomic bounded IO primitives. A root-owned, non-writable system `/usr/bin/flock` may be used only as an optional admitted Linux capability; invoke without shell or PATH lookup, inherit only the verified lock descriptor, bound and drain the child, hold the open descriptor throughout the ledger session. Never unlink the lock file or infer stale ownership from a timestamp. Contending instances deny; process death/descriptor close releases the kernel lock. Missing/unsafe capability denies ledger use, not Basic Search. No new required dependency or install.

The current anchor is trusted under the ADR-0021 host/OS boundary; digest binds the complete immutable snapshot (schema, root, epoch, revision, predecessor and bounded canonical records). The snapshot directory alone is not trusted. The host-private directory topology and OS identity are trusted; validate ancestor ownership and deny group/other writable ancestors except root-owned sticky directories. An attacker who can replace the trusted directory topology or anchor/lock, or roll back all trusted state, is outside this guarantee; no claim of hardware/cryptographic anti-rollback. Verify exact root and directory/lock identity at each operation. Strict canonical schema, unique sorted source paths, bounded counts/bytes, no note body, raw credentials, consent or grants. Native-create and baseline provenance only; imported/marked records require later contracts. Backend records never authorize lifecycle, source eligibility or egress; the admitted host caller must prove transitions and bind freshly observed originals in 2e3.

No automatic initialization or baseline on missing anchor. Explicit host-authorized initialization creates an empty new epoch only from demonstrably empty backend; missing anchor with any snapshot/staging evidence denies recovery. Actual durable initial-epoch authorization/recovery is separately integrated in 2e3. Expected-anchor CAS prevents stale commits. Fsync private directory ancestry, immutable new snapshot and its directory before atomically replacing the current anchor, then fsync anchor directory. Recover only the trusted current anchor's exact snapshot, never an orphan or prior version; a valid recovered anchor is the commit point after crash. Ambiguous publication poisons the live session; no retry/fallback. Retain the previous snapshot until anchor fsync, then remove only bounded known unreferenced private artifacts under the same lock. Refuse unrecognized or unsafe filesystem entries. Close drains the current operation before releasing the lock; no unbounded queues.

Acceptance: real Linux Node filesystem/lock tests with independent instances and process-death release, initialization/reopen, stale CAS, canonical schema, changed root, replayed/tampered/foreign snapshots, corrupt/missing current anchor, orphan/staged crash recovery, unsafe links/permissions, resource limits, cancellation/close, and existing full regression. Synthetic directories only. This slice proves the backend substrate on the measured Linux Node environment, not Obsidian host integration, native lifecycle event trust, trusted-import/writer admission, or other platforms. Actual isolated Obsidian backend capability and lifecycle verification remain mandatory in 2e3. No new model downloads or production Vault operations.
