# OKS-02A — Synthetic corpus and lexical baseline
Base: 91676ca8f3a69b423f5b3f77eeeb43dfc1eda980. Profile: ITERATION.
Authority: AGENTS, SDD, SPEC CAP-02/10 (partial AC-02/10), CAP-06 provenance, ARCHITECTURE Data and contracts, ADR-0001/0002/0003, ROADMAP, REUSE, SECURITY, benchmarks/README. Dependency: merged PR #4. English public artifacts only.

## Scope and implementation
- Build independently authored deterministic synthetic Markdown corpus (at least 18 distinct sources, RU/EN/mixed), nested headings, clauses and IDs, properties, wiki-links, lists, tables, appendix, close distractors, explicit exceptions/negation, duplicate content, empty and malformed cases. Use fixed UTF-8 bytes and relative paths; manifest with version and SHA-256; no real vault, prior code or data. PDF/DOCX and OCR fixtures extend corpus in 02B; tokenizer/chunking in 02C.
- Freeze at least 30 authored queries across disjoint tuning and held-out groups (at least 15 each), positive/ambiguous, exact IDs, technical tokens, hard negatives and unanswerable cases. Grade source-span and document relevance 0/1/2; document relevance derived from span judgments; explicit unanswerable labels. Include independently specified expected extraction structures/spans. Before writing parser/retriever or running search, author corpus/labels/protocol, validate paths, literal lines, digests and commit that freeze separately. Do not revise held-out labels to accommodate results. Report known limits of synthetic sample and relevance judgments. The evaluator alone consumes labels; retrieval never sees them.
- Define a small neutral typed canonical source-block representation independent of Markdown/Docling. Preserve exact UTF-8 source hash, source-relative identity, ordered blocks, original text and unambiguous one-based line and character/byte span convention, hierarchy, type and provenance (explicit unavailable values); table rows/cells and clauses; properties/wiki-links retained without graph traversal. Test meaningful text coverage against independently authored oracle, exact source slices including CRLF and Unicode; empty/unsupported/invalid/partial input explicitly diagnosed, no silent text loss. Prefer existing maintained parser if needed only after license/pin review; bounded Markdown subset with stdlib is acceptable if explicit limitations and unsupported cases surfaced.
- Reuse engine/scope.py bounded reads and ADR-0003 storage constraints; inspect storage.py and use existing FTS5 mechanism where compatible, extend narrowly where justified. No duplicate persistent storage architecture, no fake vectors. A synthetic-only in-memory lexical FTS5 index over canonical blocks is allowed with rationale if production storage requires dense records; keep separation documented and reusable lexical query path. Parameterize SQL, safely quote literal terms, preserve RU/EN and exact punctuation-rich technical identifiers, deterministic tie ordering, bounded query/result/input, no silent fallback. Return exact original evidence and locator, not generated answers; reject stale/missing sources at retrieval boundary. Preserve existing foundation contracts and tests.
- Benchmark harness uses same lexical entry point as tests; corpus and judgment hash, code identity, versions/configuration, reproducible commands, per-query ranks/metrics with Recall@5/10, Precision@5/10 (fixed denominators), graded nDCG@5/10, MRR, exact-ID hits, unanswerable false positives, document and deduplicated span units separately, parsing coverage/locator validity, warm timing, index size and resource observations. Record actual counts and results, no claims of hybrid or semantic quality. Before held-out evaluation freeze scoring definitions and gates: zero invalid locators, zero unexplained coverage loss, zero forbidden/stale source evidence; report baseline effectiveness without post-hoc quality thresholds, no noninferiority claim until paired experiment. Run held-out once after tuning implementation fixed; any correctness fix separately tracked, no label changes.
- Add focused positive/negative tests and full lightweight regression; include path escape/symlink, invalid UTF8, size bounds, injection-shaped queries, punctuation collisions, version/label mismatches, deterministic ranks, no-match, stale/deleted source, malformed/empty input. Update benchmark and engine documentation, roadmap contract link; record actual limitations and evidence. Keep files cohesive, no new dependencies unless approved after review. CI must include tests/harness deterministic invariants, not timing thresholds.

## Exit gates
V02A-01 deterministic versioned corpus/source oracle and frozen query labels with independent pre-search commit.
V02A-02 canonical extraction of declared Markdown subset, exact valid locators and complete explained coverage; negative behavior.
V02A-03 reusable bounded lexical path, safe exact evidence, stable ordering, scope and freshness tests; no vectors.
V02A-04 reproducible, versioned baseline and split-specific per-query metrics, actual measured results and limitations.
V02A-05 full regression, license/type/build checks, independent exact-head review and hosted CI before verified squash merge.

## Operational exclusions
No Docling/OCR, tokenizer, model downloads, embedding, hybrid/RRF, UI/IPC expansion, live vault, host settings, external document egress or copied private code. No parallel heavy tasks. Bounded Codex session, no commit except the corpus freeze, no push/PR/merge by implementation worker. Orchestrator owns independent review and delivery. No raw local paths/logs in public artifacts.
