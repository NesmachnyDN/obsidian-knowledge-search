# OKS-06 P0.2b2 — native exclusion authority adapter

Base: 46e5b8b9fc6536c29f5b3ef792c8d5065cad085b. Authority: owner requirement #149, ADR-0023, SPEC CAP-01/06/08/10, AC-01/06/08/10 and ROADMAP P0; #146/#150 accepted prerequisites; #105. #149 specifies the authoritative UI/input within the already accepted hard-scope architecture. It supersedes the future parallel settings/UI proposal in older P0 contracts, not the exact-path core or historical tests. No second user-managed list.

Implement one isolated host adapter for the observed Linux desktop Obsidian 1.15.1 private native config getter, native matcher and config-changed event (not a stable public API). Delegate matching to Obsidian; do not copy/approximate its pattern semantics. An unsupported or unobservable host/config/matcher denies capture, never defaults to allow. Recognize actual native default absence only in the verified version/shape with the observed null config and null compiled filter set; explicit empty array requires an empty compiled array. Reject undefined, inconsistent or malformed state and missing API. The native getter does not distinguish an absent key from an explicit null with the same default semantics. Bound and snapshot raw strings, retain exact host/method/compiled-filter identity and validate current configuration before/after each native match. Subscribe before capture; any native config-change event permanently revokes the lease (conservative, including unrelated changes); missed observable config/method replacement also permanently revokes it. Change-then-restore cannot revive an earlier revision. Fail closed on malformed matcher output/errors, reentrant change and disposal. Notify the owner synchronously after sealing the lease. Intersect with the existing optional exact hard scope, never extend it. No source reads/writes, provider calls, private paths in diagnostics, new dependencies or producer.

Use the existing HardSearchScope contract with an explicit current() guard on the native lease. hasExclusions describes configured restrictions, NOT proof of current authority; downstream integration must check current even for default/empty config and retire all owners before publication. This slice is an isolated tested adapter, not native activation. No main.ts call-site change until atomic restart/retirement and all affected routes have a safe integration contract. Historical lifecycle inventory, attachment owners, physical cache cleanup, advanced/dense/chat/history/egress integration and other host versions remain subsequent gates. Tests include host version/shape, actual default/empty, file/folder/regex delegated matching, exact scope intersection, event and missed changes, matcher/host replacement, reentrant and throwing matcher, malformed settings, cleanup and unique revision. Verify the adapter itself in an isolated synthetic real application profile on the supported observed Linux version. Full regression, exact independent review, CI and publication guard before merge.

Observed host compatibility evidence (isolated synthetic Linux desktop Obsidian 1.15.1): the initial native getter and compiled filter state were both null with all eight fixture paths permitted; explicit empty arrays permitted all eight. Rules Control/, /\.pdf$/, exact.md excluded nested Control and case-variant control paths, PDF, exact.md and exact.md-more.md; nonmatching sibling Control-old and other.md remained permitted. A native config-changed event revoked the previous lease before any further match; changing back to the original configuration created a distinct revision. The isolated probe used the adapter module, not a second matcher or a real Vault. This is compatibility evidence for the adapter only, not host-wide OKS acceptance; the full activation, all-route and native version migration gates remain open.
