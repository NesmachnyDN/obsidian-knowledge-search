# POLICY.3d2 — ephemeral chat lineage and verified transcript read

Base 0f20e73a800a3f0de0c3262c03585b182a50b811 (#90). AGENTS, SECURITY, SDD, SPEC AC-11-CHAT-02/03 and AC-11-POLICY-01/03, ADR-0018/0019, POLICY.3 and OKS-06H.2, #78. Standard bounded PHASE_RUN.

Keep history local-only and ephemeral under the existing retained SearchController. Each completed turn records the exact scope selector and scope/generation/source/config identity, historic policy and ordered payload/source digests, and constituent question identities, digests and classification; canonical citations remain attached to verified generated claims. Historical lineage is not reusable consent, a credential, or eligibility for exporting generated answers. Do not retain the credential epoch, deadline, grant, or any reusable authority; previous answers are never included in provider input. Include lineage in existing per-session and aggregate byte/count caps, with whole-turn eviction and no persistence. Existing strict pilot remains supported. The policy host supplies a local historical scope state fingerprint independent of credential and operation lifetime; it cannot issue a decision or grant. A prospective profile missing this fingerprint capability fails closed for retained chat. Pin fingerprint across preview, dispatch and publication, and invalidate incompatible prior questions before reuse. Each follow-up still requires explicit selection, fresh attestation, exact new preview/consent and current source/policy checks.

Synchronous history read returns only detached metadata; content read must reacquire the exact original scope using the existing engine and shared physical scoped slot, verify membership and all source versions (including non-cited scope members), exact canonical citation spans, current policy fingerprint, config, generation and source revision. Recheck after asynchronous operations and deny stale/foreign/unavailable reads with logical cancellation and physical drain; clear incompatible history. No generation/provider call for local history read. Native history presentation and guarded citation navigation are subsequent slices and must use verified local reads, not synchronous metadata as content authorization. No changes to operational/provider/real-host gates, attachment support or 30s turn budget.

Tests: retain existing bounded-history, exact synthetic wire and lifecycle checks, measure actual verified transcript bytes, verify no grant/credential/deadline in history, policy drift invalidates prior IDs and content, missed source edit in a non-cited member denies content, cancellation retains the physical slot and publishes no stale transcript. Full local validation, independent exact-HEAD review, CI and post-merge regression.
