## Actual admission boundary

The native adapter implements the currently admitted local synthetic/public pilot only. Disabled, invalid and cloud configurations can still retrieve local evidence but expose no token/classification/preview/confirm controls. The prospective note-policy branch (no manual excerpt classification) remains unadmitted and must be wired and exercised when the provider admission/transport gate permits it; no cloud grant, egress or implied readiness in this PR. Settings uses a generation-only public Modal with the same preference/check renderer and patchSettings transaction; no private settings API. Native registration, UI state and synthetic transport are exercised via the Node host adapter; actual isolated Obsidian host and visual smoke remain separate.
