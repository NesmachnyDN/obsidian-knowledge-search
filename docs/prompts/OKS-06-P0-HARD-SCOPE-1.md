# OKS-06 P0.2a — hard search scope at the standalone source boundary

Authority: ADR-0023, CAP-01, AC-18, #105, #137. Base: 2acf8b19f2a8713ae7c06b49adf37500bcfcf0d2. Bounded standard SDD; no production settings activation, cache migration or provider changes in this slice.

Implement a provider-neutral immutable local scope configuration for exact vault-relative file and rooted folder exclusions, with strict bounded path validation, deterministic revision and no globs, normalization, case folding, or path-prefix ambiguity. Scope is separate from semantic corpus and processing eligibility. Deny invalid paths; empty config preserves current behavior. A standalone reader with this explicit scope must exclude paths from enumeration and reject excluded direct reads, version hints and original/lifecycle descriptor proofs before I/O. Historical complete-Markdown lifecycle inventory requires the full native domain; reject a scoped reader's complete-inventory operation rather than silently reinterpret it as a full-domain proof. Keep historical default reader behavior intact. No live caller selection, no authority or grants, no attachment coverage claim. Later integration must retire prior index and AI/history/graph authority atomically, enforce advanced/attachment routes and all owners, provide persistent settings/UI and prove no stale evidence or reuse. Preserve scale bounds, underlying descriptor protection, original bytes and independent Gate A/B/C. No real Vault, provider, or producer access.

Test invalid/ambiguous path forms, exact path and segment-root exclusion, sibling/prefix collisions, config immutability and deterministic revision, explicit file/folder filtering, direct read/version/lifecycle denial, valid neighbor reads and full inventory rejection without changing the historical unscoped contract. Standard typecheck, build, synthetic Node/Python and independent pinned review before merge. Not complete hard-scope acceptance.
