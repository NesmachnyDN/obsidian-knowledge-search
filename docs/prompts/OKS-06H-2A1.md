# OKS-06H.2-A1 — Canonical scoped retrieval substrate
Base: f020865716050a38dcfa5a92497b4ce110b75dff (independently accepted PR #65; integration pending due to GitHub outage). Maintainer-authorized temporary local continuation only; no publication, no aggregate merge exception. Authority: OKS-06H normative range mapping, SPEC AC-11-CHAT-01–04, AC-06/07/09/10/11, ADR-0018, SECURITY, SDD.
Implement the smallest complete canonical retrieval substrate for selected editor ranges. Add bounded typed range constraint tied to exact source identity/version to the existing lexical SearchRequest and its strict validation, apply it before candidate ranking and context expansion, preserve existing absent-range behavior, reject empty/invalid/stale/mismatched ranges without widening. Implement pure exact editor UTF-16 coordinate to original UTF-8 byte and code-point half-open interval mapping with source digest and whole-buffer equality after newline normalization only, respecting canonical parser bounds/encoding. Reuse canonical source locator and parser mechanisms. Require every locator and represented excerpt to be contained; no clipping/fabricated evidence. No separate retrieval engine. Add deterministic tests including LF/CRLF/CR, terminal newline, astral and combining characters, reversed/multiline/partial/empty/invalid selections, unsaved mismatch, stale source, no out-of-range ranking or expansion, ordinary lexical regression. No host UI, chat generation, credentials, network/provider calls or production Vault in A1; shared host-owned chat authority and selector resolution follow in A2, native UI later. Do not claim chat readiness. Typecheck, tests, build, diff hygiene; independent exact-head local review. Record local evidence, no push.

Implementation boundary: nonempty lexical text requests only; the exact range is paired with a singleton source scope. Explicit source-level metadata predicates may restrict eligibility, never supply scoped evidence or context; metadata-only/dense/hybrid range requests are rejected. The host coordinate mapper accepts the full editor snapshot locally, returns only immutable identity/version/intervals, and the engine reauthenticates endpoints. Host ownership and editor mutation fencing after mapping are A2 requirements, not claimed here.
