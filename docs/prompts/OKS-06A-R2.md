B-R2-TERM-04 remediation supersedes only the three-pass delivery mechanism of TERM-03. Notifications are coalesced invalidations, not an event log. ### Systemic lifecycle retirement (LIFE-01–17) — proposed contract, author remediation in progress

Traceability: AC-01/06/07/09/10/11, ADR-0015 and the preceding immutable R2 amendments. No earlier acceptance record is superseded by this proposal. The common defect class is losing an outstanding physical retirement obligation when logical revocation, callbacks, and lifecycle notifications share a stack or a generic later transition. The implementation must remain within the existing SearchController, DenseAuthority and concrete owner mechanisms; no additional public authority API, provider scope, storage backend or parallel event bus.

| From | Trigger | Logical commit before callbacks | Retirement and completion |
|---|---|---|---|
| ACTIVE | Shared search reset, source event, settings or control | Invalidate old revision, dependent evidence, grants, navigation and dense/D8 ownership; reserve the new revision where appropriate | Attempt each pinned obligation independently; no dispatch or old publication before completion |
| LOGICALLY_REVOKED | Physical callbacks | Closed admission and publication; source generation invalidated for source changes | Record failures, retain exact owners and paths; nested work joins the bounded wave without retrying failed items |
| RETIRING | All obligations complete | No old rights restored | Commit and deliver coalesced observer snapshots; reopen only when every applicable settings/storage/terminal barrier permits |
| RETIRING | Any obligation fails | Closed affected authority, typed failure and settled pending callers | FAULT_LATCHED; unrelated notifications or revisions do not erase work |
| FAULT_LATCHED | Explicit recovery | Still closed; do not reuse old consent or bearer capabilities | Retry pinned outstanding work once per recovery; stay latched on any failure |
| ANY | Terminal unload | Seal all rights before callbacks; no new work/persistence | Independent concrete owner teardown; preserve started persistence and storage drain barriers; no return to ACTIVE |
| ACTIVE | Role-local cancellation/expiry or ordinary observer delivery | Only role-local rights are revoked; normal observer delivery is not authority revocation | Preserve independent roles and Basic search under ordinary provider failure |

Author implementation decisions: the existing Rebuild control is the explicit recovery entry for unresolved source/shared-evidence obligations. A bounded ledger has a maximum of 4096 outstanding items and 4096 attempts per wave; overflow is fail-closed and requires terminal disposal/reinitialization, not silent reopening. Source events capture concrete owner references and immutable paths; successful callbacks are removed and failed callbacks retained. Dense source batches attempt both paths before abort. Shared evidence aborts retain their concrete owners. A source epoch distinguishes Advanced source freshness from ordinary lexical latest-wins. These decisions require independent review, including the overflow/reload reconciliation policy and whether retention of a batch rather than each individual store owner is sufficient.

#### Systemic continuation: role, process and storage ownership

The existing retirement protocol now distinguishes shared/source obligations from role-local evidence retirement. A failed role-local abort retains the exact AbortController and blocks only that role; an explicit cancel outside the failed callback wave may retry it. Shared reset revokes both deadlines and previews before physical cancellation. D8 removes the logical slot and resolves the waiting result read before the pinned abort callback; a failed abort blocks dense admission, and a still-running verification keeps the independent drain fence. Dense UI retirement pins its navigation callback; source-batch retry retains the same store and abort owner even if the instance-local store changes. Earlier failed host retirement remains ordered before admission of any replacement target (LIFE-12). Ordinary generic-hook recovery and explicit source rebuild are deliberately distinct.

An Advanced process has separate logical retirement and physical stop. A failed stop retains the original Job and rejected stop promise, not merely the poison flag; an absent active slot is not proof of shutdown. Source-event stop obligations include both the runner and the manager operation drain. Their storage barrier is published in the existing reload-safe ingestion barrier and their source fence is retained until completion. A rejected drain is terminal-only in that controller; reload does not clear the rejected storage barrier. Basic reload remains independent and performs authoritative source reconciliation. Explicit source rebuild is not a process-exit attestation. Both manager drains must be attempted independently on terminal or settings teardown. Basic and dense writer-close barriers reserve the exact detached owners before retirement callbacks. No new public API, process supervisor, model admission, storage backend or network route is introduced.

Runtime preference changes advance the source epoch. Persisted preferences remain authoritative when source retirement interrupts application; runtime application remains fenced until source obligations are reconciled and the committed settings are explicitly reapplied. Presentation-only edits retain their existing behavior. Advanced source reads, index/search publication and navigation check current source/runtime authority at awaited and editor-side-effect boundaries. A previously dispatched host action cannot be undone; no subsequent old-authority side effect is permitted.

The adversarial suite covers original and nested source-event failures, role-local and shared abort faults, D8 pending/owned/read phases, exact Dense store retry, delayed and rejected Advanced stop and reload, independent manager/writer shutdown, Settings/source overlap, and source-ledger overflow/reconciliation. Overflow is a deliberate bounded fail-closed policy, not successful retirement; no new source authority is granted in that instance. The immutable historical partial-settings reproducer continues to report Missing expected rejection because the obsolete second idle-host retirement is absent; preserve the source and record the outcome alongside the independently observable LIFE-12 cases, rather than modify the historical test or claim it passed.

Author gate remains distinct from independent acceptance. Real isolated Obsidian functional, visual, locale and package rollback checks use generated data and synthetic loopback responses only. CI/CodeQL and independent full-diff review must be evaluated at the pushed exact candidate HEAD. B-Rerank and issue #49 remain NOT ACCEPTED/OPEN. The preceding proposed-contract completion gate is not waived by this implementation or by an author test result.
