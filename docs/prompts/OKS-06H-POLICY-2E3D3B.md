# POLICY.2e3d.3b — native initial-baseline preview and confirmation

Base: `deb5a3a81442902ba58d716b655f52ff4ffc7ecd`. Authority: `AGENTS.md`, `SECURITY.md`, SDD, SPEC AC-11-POLICY-02/03, ARCHITECTURE, ROADMAP POLICY.2, REUSE, ADR-0019/0021, predecessor POLICY.2e3a/2e3d.1/2e3d.2a/2e3d.2b/2e3d.3a contracts, and issue #79. This is a bounded native-host adapter slice. It does not admit providers, trusted imports, writers, roles, grants, egress, production Vault access, or installed-plugin modification.

## Contract

Expose one actual Obsidian command, localized at command registration in English and Russian. The command may only ask the captured `NativeLifecycleOwner` for its existing local preview; it has no alternative tracker, ledger, transaction, or immediate-confirm route. A modal shows the complete local Markdown inventory, scope wording, exact count, paths, and monotonic remaining TTL. It clearly says that this is local existing-material classification only: no access grant and no Vault-original write. Empty complete inventory remains permitted only through explicit confirmation.

The modal holds the exact owner and returned preview object. Its only affirmative action calls `confirmBaselinePreview` once. Modal close, unload, a native source event, owner replacement, rule/root/session/host change, expiry, or an unavailable owner cancels or denies the exact preview and retires/drains through the existing owner transaction. No close path creates a replacement owner. Presentation returns typed local outcomes: `admitted`; `cancelled` before confirmation; `cancel-requested` during confirmation (not a rollback claim); `denied` with stale, expired, retired, or verification-failed reason; `committed-not-live`; or `uncertain-publication`. Source classification is not published before durable commit plus fresh proof. No automatic reset or rebaseline is allowed after cancellation, invalidation, ambiguity, corruption, or an unavailable/retired owner.

Startup events remain conservative: observed ambiguous legacy evidence blocks fresh admission, never classifies existing startup files as verified-new, and is not reset to obtain readiness. An explicit user plugin reload in a settled host may establish a new pristine session; it is not an automatic retry or rebaseline. Basic Search remains independent. The lifecycle owner is optional and its failure cannot make Basic unavailable. Trusted import provenance, native event authenticity, lifecycle transitions and later marking writers remain separate contracts.

## Acceptance

Add focused adversarial owner tests for typed cancellation/expiry/retirement and no replacement baseline. Add an actual isolated Obsidian smoke mode using the existing harness and a verified package. It must use the real UID plus direct-network denial, begin with an unseeded cold host, prove no automatic epoch or startup verified-new state, explicitly reload into an unseeded fresh owner, execute the registered host command, dismiss once, reload, dismiss during a controlled asynchronous confirmation boundary (no committed baseline), reload, explicitly click native confirmation, reload and restore durable state, then invalidate source/owner authority and prove no rebaseline. It must check original fixture bytes before/after admission and never invoke the historical 2e3a/2e3c fixture-ledger seeding path. The smoke remains unavailable rather than weakened where its sandbox cannot support real UID, lock, or host execution.

Run focused tests, typecheck and build where available. Preserve WIP; no commit, push, merge, provider action, production Vault write, or installed-plugin mutation is authorized. Independent exact-HEAD review and normal SDD gates remain required before delivery.
