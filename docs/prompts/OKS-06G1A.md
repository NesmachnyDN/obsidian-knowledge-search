## Registry and canonical boundaries (target contract)

- One host-owned, versioned, immutable allowlist: each entry binds adapter ID/revision, exact supported content types/extensions, bounded detector identity/revision, supported platform/profile, capability flags (text, native anchors, OCR, embedded content), dependency/assets identity, normalization/locator schema, resource policy and explicit readiness. Closed schema, unique IDs, deterministic selection; no discovery or execution of arbitrary plug-ins. Detect from bounded verified bytes and container structure (not suffix or cached MIME alone). Require compatible suffix and unique supported format or reject mismatch/ambiguity. For OOXML inspect required content type and relationships with bounded archive validation; OLE container magic alone cannot distinguish DOC/XLS/PPT/MSG. XML/diagram and text encoding detection must be explicit, bounded and non-executing. Known formats without an admitted adapter report unsupported/unavailable.
- Canonical flow: current authorized original -> verified exact bytes/digest -> bounded detector and explicitly selected profile -> independent validated ParsedDocument -> private extraction cache -> canonical chunks/lexical retrieval and separately accepted AI modes. No second source authority, knowledge model or search stack. Local lexical document use must not require AI credentials or model tokenizer. Preserve existing standalone Markdown path unchanged. Evolve the wire and shared evidence/locator contracts by explicit version/parity migration; do not turn unvalidated native metadata into verified original evidence.
- Locator extension candidates: native page/item/cell coordinates; sheet identity + one-based row/column and value/formula/cache distinction; slide ordinal + shape path/notes/table cell; diagram page ID + cell/explicit edge endpoints; image pixel region + OCR engine/representation; message body/header stream identity and bounded embedded attachment chain (parent digest, storage/stream identity, child digest); explicit file-only location where no stronger anchor can be proven. Text byte offsets only for verified actual original byte ranges, including declared encoding. OCR and reconstructed table text remain derived, not byte-exact source spans; missing location/coverage gets explicit partial reason. Card context is separate from original content.
- Enumerate and resolve all declared ownership relations in a reviewed per-Vault ownership contract using current original notes and exact attachment identities/versions. Links/backlinks alone are not ownership. Multiple verified owners intersect restrictions; unknown/incomplete/conflicting ownership denies automatic AI retrieval. Independently validate file rules, scope, capability and ADR-0019 processing policy; ai_indexing alone grants neither local access nor external processing. Local authorized lexical document retrieval and original navigation remain independent of automatic AI corpus eligibility. Revoke stale ownership, source and rule leases before publishing/using evidence; rename/delete/missed-event reconciliation cannot silently broaden scope. No owner contract admitted in this slice.
- Generalize ADR-0011 extraction profile identity from exact adapter/detector/options/assets/normalization/schema versions using existing canonical serialization and domain-separated SHA-256. Cache content key binds source byte digest and profile ID; private per-root store isolates authorization. Rebind verified source/locator identity on compatible reuse, never trust old path or source-specific block IDs. Cache validated ok/partial/empty with diagnostics; failure retry metadata is not content. Chunks/embedding space/lexical generation identities remain downstream, not parse-key inputs. Preserve staged atomic commit, bounded retention, crash recovery and current source checks. No parsed-cache sync; 06D separately proves implementation.
- All parser jobs are untrusted: preflight bytes/container limits, archive names/duplicates/links/ratios/actual expanded bytes, XML entity/external reference denial, bounded recursion and output; forbid macros, formula execution, active HTML, external relationships, remote resources, rendering/includes and arbitrary command arguments. No conversion/child process without measured isolation and process-tree cancellation. Source mutation and egress prohibited. Typed outcomes distinguish pending, ready, partial, empty, unsupported, locked, disabled and failed; failures cannot be cached as successful content or silently fall back.

## Frozen experiment specification (before new extraction)

Use two separately generated synthetic examples per required format/extension (including both plain and compressed drawio; UTF-8 and explicit CP1251 TXT; separate text and scan PDF; standalone Mermaid and PlantUML variants). Use generated RU/EN architecture vocabulary; unique tokens appear only in the intended original content, never filename, note title, metadata or another fixture, except deliberate duplicate-link case. The generator and manifest must be independently reviewed and committed before opening candidate results. For legacy Office and MSG, use generated valid format artifacts with independently verified bytes/structure and provenance; do not rename OOXML or EML to fake legacy formats. If generator unavailable, mark fixture blocked, not pass. Use existing 02B artifacts only as an unchanged regression set.

| Fixture family | Required positive judgments (two independently authored cases each) | Required negative / honesty check |
|---|---|---|
| MD, TXT, diagram source | RU/EN identifiers, CRLF/Unicode, exact original byte/line locator; source-only label token | malformed or ambiguous encoding, external include not resolved, no fabricated relation |
| PDF text/scan | unique per-page heading/table value, separately identified RU/EN OCR line; verified page/region | encrypted/truncated, blank page, missing native geometry stays partial; no OCR text labeled verbatim |
| DOC/DOCX | unique paragraph, header/footer, table cell, embedded image token where claimed | invalid container/external relationship, merged cell coverage, unavailable OCR explicit |
| XLS/XLSX | distinct sheet/cell tokens with intervening blank row, formula and separately cached value or missing cache | no formula evaluation, external link, stale/missing cache not inferred |
| PPT/PPTX | multiline first shape, grouped shape, table cell, notes, image text where claimed | no dropped title continuation; no inferred slide text, unsupported notes/images partial |
| VSDX/drawio | second-page shape label, edge label, explicit source/target identities, user-object label | ambiguous/dangling edge, malformed XML/deflate, unsupported implicit visual relation not inferred |
| PNG/JPG/JPEG/BMP | large clean Cyrillic and Latin identifier strings in each format, image region when supported | blank and noisy images, oversized dimensions/decompression, failed OCR not empty success |
| MSG | subject, sender/recipient/date, body, nested synthetic text attachment distinct from name; exact parent/child digests | missing/duplicate stream, malformed compound file, conflicting body alternatives, depth/size limit |

Freeze filenames, byte hashes, expected tokens, content layer, anchor/locator, allowed scope/owner fixtures, unsupported states and negative queries as an independent manifest. Include two owning notes with conflicting corpus settings, orphan, unrelated backlink, deleted/renamed source, same bytes under different identities, stale owner/property, and authorized linked-card navigation. Compare on identical fixture bytes, profile settings and fixed ground truth; report each case and denominator rather than aggregate-only success. Candidate tests must actually query canonical extracted text and verify source identity/locator; parser success or metadata hit is not a content-only retrieval pass. Final Gate C requires real plugin retrieval/navigation and platform-specific acceptance, not this experiment.

**Predeclared pilot acceptance/selection:** all required clean non-OCR exact tokens (100%) and expected original identities/locators; zero hard-negative false hits, fabricated locators, unauthorized reads/writes/egress, or unreported missing content. For clean synthetic OCR lines measure CER and WER after NFC and whitespace normalization; target CER <= 5%, WER <= 10% and 100% designated technical identifiers; do not normalize away punctuation/identifier errors. No automatic format admission from a partial case: record missing optional coverage and require independent acceptance for the stated scope. For noisy/adversarial inputs no accuracy claim; typed partial/error required when evidence insufficient. Use five repeated measured invocations per candidate/fixture on the same host, separate process-cold from warm reuse, report median/max and raw samples (no population-percentile or broad accuracy claim). Compare resource cost only among equivalent coverage profiles. Before execution verify one isolated job, no internet/network, <= 4 GiB process-tree memory, no swap, <= 2 CPU quota, <= 64 PIDs, 120 s total deadline, <= 64 KiB source, <= 256 ZIP entries, <= 8 MiB actual expansion, <= 8 PDF pages, <= 8 MiB response, and existing stricter adapter limits. Candidate-specific limits for nested attachments (depth 2, <= 16 children total), image (<= 16 megapixels), drawio decompression (<= 8 MiB), and table enumeration (<= 8192 cells) are proposed experiment caps, not production capacity or performance SLA. Deny when the host cannot enforce them. Record time, peak charged memory/RSS, CPU, artifact/disk footprint, process-tree termination, coverage, cache hit/miss and dependency cost. Measure cache reuse separately once 06D exists; do not fabricate cache results. No held-out retuning or acceptance threshold changes after observing results without a new reviewed experiment.
