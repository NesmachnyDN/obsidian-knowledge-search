# OKS-06UX-INDEX.1 — preserve dirty work through supersession

Base 4654d80ada68c0a083c007e2f31f19a8381048be (#94). Issue #67, 04A, 05E, AC-08/09/10, ADR-0008/0015, 06UX. Audit: StandaloneEngine.run consumes the pending set/full-reconciliation bit before asynchronous source IO. A later event retires the candidate but can discard the previously consumed obligations, leaving a degraded generation until another query triggers a full scan. Retain all dirty obligations across supersession using the existing bounded single-flight queue, no additional timers, workers, storage, or remote work. Preserve existing cancellation, resume/recovery, unknown-publication, policy-read drain, bounded overflow and deterministic failure behavior. No retry spin on permanent errors. Verify fresh final CURRENT without query-driven recovery. Reproduce two different modifications while a prior read is pending; test full reconciliation superseded by a narrow event, bounded overflow and cancel/unload/restart regression. Existing source/version/consent gates remain. No production Vault or provider.
