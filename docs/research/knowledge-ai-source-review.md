## Sequencing and acceptance

1. **05P/06UX/#66/06UX-CHECK/06F:** audit delivered role adapters and UI first; add curated optional model profiles, truly role-specific tests, explicit status and safe model revision migrations. No startup download or mandatory weights; generation/rerank change does not force dense rebuild.
2. **04A/05E/06UX/#67/06G.2:** measure deferred work with real source-version guard and truthful coverage. Synthetic event storms, delete/rename during search/chat, cancellations, parser revisions, crash recovery; zero stale or forbidden evidence. Never create a second active dense space.
3. **06H.1–06H.3:** adapt the source's streaming/citation/top-K/neighbor UX only within explicit Vault-wide/selected scope, per-turn current evidence, bounded ephemeral history, accepted generation API and separate Gate B-Generation review.
4. **06A:** benchmark real rerank quality/latency against no-rerank. **After 06H.3 only**, optionally evaluate document summaries/backfill against lexical-plus-neighbor retrieval with frozen source/cost/provenance benchmarks.

**Non-decisions:** upstream source availability is not proof of production stability, offline package completeness, model revision verification, cloud approval, exact source freshness, per-task support or cross-platform parity. Third-party models/dependencies require separate licenses and artifact checks if any component is reused. No code import authorized by this document; any future transfer requires code-level license/provenance and independent acceptance. All SDD Gate A/B/C and ADR-0015/0016/0017/0018/0019 boundaries remain in force. The subsequent accepted ADR-0019 governs note eligibility, provider admission and explicit authorization separately, including inherited derivative restrictions; reuse must not introduce automatic fallback or egress. POLICY.4 remains deferred.
